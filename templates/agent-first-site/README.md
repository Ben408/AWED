# Agent-first site starter (FWP)

Document-driven Next.js site template patterned on bencornelius.com practices:

- Marketing pages as `content/pages/*.page.yaml` (block catalog)
- Articles as `content/articles/*.mdx` with TL;DR-friendly structure
- Site-wide agent facts in `site.yaml`
- No freeform HTML authoring

Copy this folder to start a new site project, then point FWP `data/projects.json` at it.

The New Site wizard is deferred; registration is manual for now.
